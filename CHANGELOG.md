# Changelog

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow semantic versioning.

## [Unreleased]

## [0.4.0] - proposed tag `v0.4.0`

### Added
- Three case studies with committed packs: the funnel lab ad campaigns, UCI Online Shoppers Purchasing Intention, and UCI Online Retail II (see each case README for licence).
- 1M-row performance check (`scripts/perf_check.py`) with the measured time in the README.
- Dockerfile, pre-commit configuration, CI matrix, coverage report.
- Resume bullets and keyword map with the command or file that proves each.

## [0.3.0] - proposed tag `v0.3.0`

### Added
- FastAPI app with typed models, an asynchronous job endpoint and OpenAPI docs.
- Minimal Next.js page: upload a spec and CSV, view the waterfall, the tree and the recommendations.

## [0.2.0] - proposed tag `v0.2.0`

### Added
- SCQA summary and one-page memo, with a golden-file test.
- Hand-written SVG waterfall and tree charts.
- PPTX deck whose slide titles are full sentences, with a methods and limits appendix.
- Command line: `decisionpack run`, `check`, `serve`.

## [0.1.0] - proposed tag `v0.1.0`

### Added
- Driver bridge with sequential substitution and exact Shapley attribution; regression against the funnel lab numbers.
- Statistics cross-checked against SciPy and statsmodels: two-proportion z-test, Wilson interval, bootstrap, power and sample size, Holm and Benjamini-Hochberg, sequential probability ratio test.
- Segment scan with minimum-size rules, mix and rate effects, multiple-comparison control and a Simpson's-paradox check.
- Hypothesis trees in YAML with a numeric MECE check.
- Impact sizing with required low, base and high assumptions; ICE and RICE with the arithmetic shown.
